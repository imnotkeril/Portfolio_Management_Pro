# Security review - Portfolio Management Pro - 2026-10-25

## Security

**Scope:** current code on `chore/audit` at `2680dbb` (includes sibling fixes `43b0f04` webhook un-mark and `9b15498` legacy DELETE 404). Whole-codebase review, not a diff: FastAPI (`api/`, `services/`, `core/`, `config/`), Next.js BFF (`frontend/src/app/api/**`, `src/lib/proxy-path.ts`, `src/lib/auth-cookie.ts`, `src/middleware.ts`, `next.config.ts`), Dockerfiles, compose. Router: webapp/saas. Money project, so categories 1, 2, 5, 7 and 8 are tier A: every path traced, nothing sampled.

**Result: P0 = 1, P1 = 3, P2 = 7, P3 = 6.** Release gate (P0 = P1 = 0) **not met**.

Severity mapping: Critical = P0, High = P1, Medium = P2, Low = P3 (`process/review.md`).

### Stack adaptations (framework is written for Next + Better Auth + Drizzle)
- "DAL owner predicate" becomes `PortfolioRepository.*` filters `PortfolioORM.user_id == user_id`, plus every service resolving `portfolio_service.get_portfolio(pid, user_id)` before it reads or writes. Grepped in all services and tested live.
- "Server Action authz" becomes FastAPI `Depends(get_current_user)` / `require_pro` on each route. Next middleware does only an optimistic cookie check, and the real check is in the API.
- `rules/auth.md` (Google OAuth) does not apply: this app uses email/password + HS256 JWT in an httpOnly cookie set by the BFF.
- Rate limits: `limits` in-memory per process (`api/rate_limit.py`), not Upstash/Postgres.
- Zod PATCH-default trap: Pydantic `UpdatePortfolioRequest` uses `None` checks and `model_fields_set`, so it does not apply.
- `pip-audit` is run inside the API image (the host pip is blocked by the SSL proxy).

### Trap-worthy (for `known-traps.md`)
- 2026-10-25 - **stripe-python 16: `StripeObject` is not a dict.** `event.data.object.get(...)` raises AttributeError, every webhook returns 400 and the user is charged with no access. Unit tests that mock objects as `{}` hide it. Use `.to_dict()` and test with `stripe.Event.construct_from(real_fixture)`.
- 2026-10-25 - **`.dockerignore` `*.db` matches only the context root.** Use `**/*.db`. Verify with `find` inside the built image, not by reading the ignore file.
- 2026-10-25 - **BFF + IP rate limit = one global bucket.** If the BFF does not forward a trusted client IP, the API limiter keys on the BFF egress IP and 20 bad logins lock out every user. Always pair the IP limit with a per-account limit.
- 2026-10-25 - **Unbounded simulation sizes** (`num_simulations x horizon`) are a one-request OOM. Bound every numeric size field in request models.
